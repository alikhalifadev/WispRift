# WispRift

WispRift utilizes high-availability, cloud-based architecture to optimize real-time data load balancing with an intelligent optimizer and load manager.

The key benefits of using WispRift include:

- WispRift utilizes high-availability, cloud-based architecture
- to optimize real-time data load
- balancing with an intelligent optimizer

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/WispRift.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

WispRift is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
